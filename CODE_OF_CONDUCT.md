# Community conduct

Be respectful, specific and constructive. Discuss behavior and evidence rather than attacking people. Do not harass, threaten, discriminate, post private information, or pressure contributors into unsafe live tests.

Keep credentials, personal paths, real task histories and private code out of public reports. Use the confidential security route described in SECURITY.md for security concerns. If that route is unavailable, do not post the sensitive report publicly; request a private channel without including the details.

Maintainers may remove inappropriate material or restrict participation to protect the project and community. Apply these rules consistently and allow contributors to clarify misunderstandings. Review mistakes and test failures openly without inventing blame or success.
