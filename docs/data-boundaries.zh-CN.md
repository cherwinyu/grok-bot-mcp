# 数据流向、凭据与隐私边界

[English](data-boundaries.md) · [Beta 范围](beta-support.zh-CN.md) · [安全](../SECURITY.md)

1. **Windows Bridge：** 读取管理员选定 Registry 和 Git 文件白名单；任务、领取、冻结结果等账本位于工作区的 `.bridge` 目录。
2. **凭据：** 两个 Routine 阶段使用不同 Windows Credential Manager 目标。存在性检测不证明有效性，严禁向 PR、Issue、公开日志粘贴真实 URL、Bearer、密钥。
3. **网络：** 只有另行授权的提交才发送包含协议字段和任务身份的 Webhook 请求；远端另外获准的工具可以获取选定源码，Bridge 无法控制提供商保留规则。
4. **本机执行：** 云端与本地磁盘分开，真实执行器及每一条桌面命令均需独立批准；白名单不是 OS 权限隔离。
5. **日志与输出：** 标识符、Registry 哈希和 `--local-details` 路径可能识别用户或机器。只有专门重建的分享导出适合公开；哈希不代表匿名。
6. **CI/离线体验：** 虚构仓库、内存传输、零真实 Webhook。CI 成功不证明某个真实云端账号已完成任务。
7. **保留：** 不能删除未知提交或冻结证据来强迫恢复；提供商的数据保留规则不受本项目控制。

对不可信任务使用可删除或另行受限的 Windows 环境。项目不承诺操作系统级完整审计、服务可用率或订阅额度。
